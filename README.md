# 📅 پلنر من | برنامه‌ریز حرفه‌ای زندگی

پلنر حرفه‌ای فارسی با رابط کاملاً راست‌به‌چپ، تقویم جلالی و طراحی مدرن — ساخته‌شده با Next.js 16 و TypeScript.

## ✨ امکانات

- ✅ **مدیریت کارها** — دسته‌بندی، اولویت، زیرکارها و تاریخ سررسید شمسی
- 📆 **تقویم جلالی** — با تعطیلات رسمی ایران و رویدادهای مهم
- 🔥 **عادت‌ها** — پیگیری زنجیره‌ی روزانه و آمار استمرار
- 🎯 **اهداف** — تعیین هدف با پیشرفت مرحله‌به‌مرحله
- 📝 **یادداشت‌ها** — یادداشت‌های سریع روزانه
- 📊 **آمار** — نمودارهای پیشرفت و گزارش هفتگی/ماهانه
- 🔔 **اعلان‌ها و یادآورها** — مرکز اعلان با نشان فوری، یادآور روزانه در ساعت دلخواه، اعلان کارهای امروز/عقب‌افتاده، رویدادها و ددلاین اهداف
- 🎨 **۴ تم رنگی** — شکوفه، زمرد، شب، غروب
- 🍀 **فال روز** — فال روزانه فارسی
- 🔄 **تبدیل تاریخ** — شمسی ↔ میلادی ↔ قمری
- 🔐 **سیاست حفظ حریم خصوصی** و پنل مدیریت مخفی (تنظیم تبلیغات و تماس)
- 📱 **کاملاً واکنش‌گرا** — از موبایل تا دسکتاپ + قابل نصب (PWA)
- 🔒 **۱۰۰٪ آفلاین و خصوصی** — همه داده‌های شخصی فقط روی حافظه خود دستگاه (localStorage) ذخیره می‌شوند و هرگز به سرور ارسال نمی‌شوند

## 🛠 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| فریم‌ورک | Next.js 16 (App Router) |
| زبان | TypeScript 5 |
| استایل | Tailwind CSS 4 + shadcn/ui |
| دیتابیس | Prisma + SQLite |
| آیکون‌ها | Lucide Icons |
| فونت | Vazirmatn |

## 🚀 اجرای محلی

```bash
# ۱. نصب وابستگی‌ها
bun install   # یا npm install

# ۲. تنظیم دیتابیس
#    در فایل prisma/schema.prisma آدرس DATABASE_URL را مطابق سیستم خودتان بدهید
#    نمونه: DATABASE_URL="file:./db/custom.db"
bunx prisma db push

# ۳. اجرا
bun run dev   # یا npm run dev
```

سپس `http://localhost:3000` را باز کنید.

> ⚠️ **امنیت:** رمز پیش‌فرض پنل مدیریت در سورس‌کد قرار دارد. قبل از هر انتشار عمومی حتماً آن را تغییر دهید (فایل `src/app/api/_lib/admin-session.ts`).

## 📦 مسیر انتشار: از کد تا بازار

مسیر کامل انتشار این اپ در ۴ مرحله:

```
گیت‌هاب  ←  هاست وب  ←  فایل APK  ←  کافه‌بازار / مایکت
```

### مرحله ۱ — آپلود در گیت‌هاب (پشتیبان + نسخه‌بندی)

۱. در [github.com/new](https://github.com/new) یک ریپازیتوری جدید (Private) بسازید.

۲. کد را push کنید:

```bash
git remote add origin https://github.com/USERNAME/planner.git
git push -u origin main
```

> اگر با ترمینال راحت نیستید: در صفحه ساخت ریپو، گزینه‌ی «uploading an existing file» را بزنید و محتویات پوشه‌ی پروژه (بدون `node_modules` و `.next`) را بکشید و رها کنید.

### مرحله ۲ — انتشار نسخه وب (برای تست روی گوشی)

اپلیکیشن به یک هاست با **دیسک دائمی** نیاز دارد (چون دیتابیس SQLite فایل است):

| هاست | هزینه | نکته |
|---|---|---|
| **لیارا** (liara.ir) | کم | ایرانی، ساده، دیسک دائمی دارد ✅ پیشنهادی |
| **Railway / Fly.io** | کم | خارجی، دیسک دائمی دارد |
| Vercel | رایگان | فقط برای دمو — دیتابیس بعد از هر استقرار پاک می‌شود ❌ |

بعد از انتشار، لینک سایت را روی گوشی باز کنید — اپ کاملاً واکنش‌گراست و از منوی کروم با **«Add to Home Screen»** مثل یک اپ نصب می‌شود (آیکون و نام اپ از `manifest.webmanifest` خوانده می‌شود).

### مرحله ۳ — تبدیل به فایل APK (اندروید)

برای بازار باید فایل APK/AAB بسازیم. بهترین راه، **Capacitor** است:

```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "پلنر من" com.yourname.planner --web-dir=public

# آدرس سایت منتشرشده را به‌عنوان سرور اپ معرفی کنید
# (در capacitor.config.ts مقدار server.url را تنظیم کنید)

npx cap add android
npx cap open android   # باز شدن در Android Studio → Build APK
```

نیازمندی: Android Studio روی کامپیوتر شما.

### مرحله ۴ — انتشار در کافه‌بازار / مایکت

چک‌لیست مدارک لازم:

- [ ] فایل APK یا AAB
- [ ] آیکون ۵۱۲×۵۱۲ (✅ آماده است: `public/icon-512.png`)
- [ ] حداقل ۲ اسکرین‌شات از اپ (از گوشی یا شبیه‌ساز بگیرید)
- [ ] توضیحات کوتاه و بلند اپ
- [ ] آدرس سیاست حفظ حریم خصوصی (✅ داخل اپ موجود است)
- [ ] ایمیل پشتیبانی

بعد از بارگذاری، کارشناس بازار معمولاً ۲ تا ۳ روز بررسی می‌کند.
