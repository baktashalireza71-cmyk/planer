# 📅 پلنر من | برنامه‌ریز حرفه‌ای زندگی

پلنر حرفه‌ای فارسی با رابط کاملاً راست‌به‌چپ، تقویم جلالی و طراحی مدرن — ساخته‌شده با Next.js 16 و TypeScript.

## ✨ امکانات

- ✅ **مدیریت کارها** — دسته‌بندی، اولویت، زیرکارها و تاریخ سررسید شمسی
- 📆 **تقویم جلالی** — با تعطیلات رسمی ایران و رویدادهای مهم
- 🔥 **عادت‌ها** — پیگیری زنجیره‌ی روزانه و آمار استمرار
- 🎯 **اهداف** — تعیین هدف با پیشرفت مرحله‌به‌مرحله
- 📝 **یادداشت‌ها** — یادداشت‌های سریع روزانه
- 📊 **آمار** — نمودارهای پیشرفت و گزارش هفتگی/ماهانه
- 🔔 **اعلان‌ها و یادآورها** — مرکز اعلان با نشان فوری، یادآور روزانه در ساعت دلخواه، اعلان کارهای امروز/عقب‌افتاده، رویدادها و ددلاین اهداف
- 🎨 **۴ تم رنگی** — شکوفه، زمرد، شب، غروب
- 🍀 **فال روز** — فال روزانه فارسی
- 🔄 **تبدیل تاریخ** — شمسی ↔ میلادی ↔ قمری
- 🔐 **سیاست حفظ حریم خصوصی** و مدیریت آسان تبلیغات/ارتباط با یک فایل JSON
- 📱 **کاملاً واکنش‌گرا** — از موبایل تا دسکتاپ + قابل نصب (PWA)
- 🔒 **۱۰۰٪ آفلاین و خصوصی** — نه سرور دارد، نه دیتابیس آنلاین؛ همه‌چیز (حتی رابط کاربری) داخل خود اپ است و داده‌ها فقط روی حافظه خود دستگاه (localStorage) ذخیره می‌شوند

## 🛠 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| فریم‌ورک | Next.js 16 (App Router) |
| زبان | TypeScript 5 |
| استایل | Tailwind CSS 4 + shadcn/ui |
| بک‌اند | ❌ ندارد — کاملاً استاتیک و آفلاین |
| دیتای کاربر | localStorage خود دستگاه |
| آیکون‌ها | Lucide Icons |
| فونت | Vazirmatn (باندل‌شده، بدون اینترنت) |

## 🚀 اجرای محلی

```bash
# ۱. نصب وابستگی‌ها
bun install   # یا npm install

# ۲. اجرا (نسخه توسعه)
bun run dev   # یا npm run dev
```

سپس `http://localhost:3000` را باز کنید.

> 💡 برای ساخت نسخه استاتیک نهایی (که در اپ اندروید و هاست‌های استاتیک استفاده می‌شود):
> `bun run build:static` — خروجی در پوشه `.next-static/`

## 📦 مسیر انتشار: از کد تا بازار

مسیر کامل انتشار این اپ در ۴ مرحله — **هزینه‌ی سرور: صفر!** (اپ کاملاً آفلاین است و هاست لازم ندارد):

```
گیت‌هاب  ←  فایل APK (اکشنز گیت‌هاب)  ←  کافه‌بازار / مایکت
                (اختیاری: هاست استاتیک رایگان برای نسخه وب/PWA)
```

### مرحله ۱ — آپلود در گیت‌هاب (پشتیبان + نسخه‌بندی)

۱. در [github.com/new](https://github.com/new) یک ریپازیتوری جدید (Private) بسازید.

۲. کد را push کنید:

```bash
git remote add origin https://github.com/USERNAME/planner.git
git push -u origin main
```

> اگر با ترمینال راحت نیستید: در صفحه ساخت ریپو، گزینه‌ی «uploading an existing file» را بزنید و محتویات پوشه‌ی پروژه (بدون `node_modules` و `.next` و `.next-static`) را بکشید و رها کنید.

### مرحله ۲ — (اختیاری) انتشار نسخه وب — رایگان

نسخه وب فقط برای کسانی لازم است که اپ را نصب نکرده‌اند؛ چون اپ کاملاً استاتیک است، **هاست استاتیک رایگان** کافی است:

| سرویس | هزینه | روش |
|---|---|---|
| **Cloudflare Pages** (pages.cloudflare.com) | رایگان | اتصال مستقیم به گیت‌هاب، Build command: `bun run build:static` ، خروجی: `.next-static` |
| **Netlify / Vercel** | رایگان | اتصال گیت‌هاب یا Drag & Drop پوشه `.next-static` |

بعد از انتشار، لینک را روی گوشی باز کنید — اپ کاملاً واکنش‌گراست و از منوی کروم با **«Add to Home Screen»** مثل یک اپ نصب می‌شود.

### مدیریت تبلیغات و راه‌های ارتباطی (بدون پنل مدیریت)

تنظیمات عمومی اپ در یک فایل است — **public/config.json** — که داخلش راهنمای فارسی هر فیلد هم هست:

1. در گیت‌هاب روی فایل `public/config.json` کلیک کنید → آیکون مداد ✏️
2. مقادیر را عوض کنید (مثلاً `adsEnabled: true` و متن تبلیغ)
3. برای عکس بنر: آن را در پوشه `public/ads` آپلود کنید و مسیرش را در `adImage` بنویسید (مثل `ads/banner.png`)
4. Commit کنید → اپ وب خودکار به‌روز می‌شود؛ برای اپ اندروید کافی است workflow «ساخت APK اندروید» را دوباره Run کنید

### مرحله ۳ — تبدیل به فایل APK (اندروید)

همه‌چیز از قبل آماده است: پکیج‌های Capacitor نصب شده‌اند، اعلان‌های سیستمی اندروید (`@capacitor/local-notifications`) کد شده، **پروژه `android/` با آیکون‌ها و اسپلش تولید شده** و دو workflow گیت‌هاب اکشنز هم آماده‌اند. رابط کاربری هم **داخل خود APK باندل می‌شود** (بیلد استاتیک)، پس اپ بدون اینترنت هم کامل کار می‌کند.

**⚡ روش پیشنهادی — بدون Android Studio:** کد را به گیت‌هاب push کن؛ تب **Actions → «ساخت APK اندروید» → Run workflow** → بعد از چند دقیقه APK را از بخش Artifacts دانلود کن. ساخت کلید امضای رسمی هم با workflow «ساخت کلید امضا» انجام می‌شود — بدون نصب هیچ‌چیز روی کامپیوتر.

```bash
bun run build:static   # ساخت رابط کاربری استاتیک
npx cap sync
npx cap open android   # روش اختیاری کامپیوتری: در Android Studio: Run ▶ یا Build APK
```

📖 **راهنمای کامل قدم‌به‌قدم هر دو روش (گیت‌هاب بدون Android Studio / کامپیوتری، امضا و عیب‌یابی): [docs/APK-GUIDE.md](docs/APK-GUIDE.md)**

### مرحله ۴ — انتشار در کافه‌بازار / مایکت

چک‌لیست مدارک لازم:

- [ ] فایل APK یا AAB
- [ ] آیکون ۵۱۲×۵۱۲ (✅ آماده است: `public/icon-512.png`)
- [ ] حداقل ۲ اسکرین‌شات از اپ (از گوشی یا شبیه‌ساز بگیرید)
- [ ] توضیحات کوتاه و بلند اپ
- [ ] آدرس سیاست حفظ حریم خصوصی (✅ داخل اپ موجود است)
- [ ] ایمیل پشتیبانی

بعد از بارگذاری، کارشناس بازار معمولاً ۲ تا ۳ روز بررسی می‌کند.

## 📂 ساختار پروژه

```
src/
├── app/                  # صفحه اصلی اپ (App Router)
│   └── page.tsx          # کل رابط کاربری (کامپوننت‌های کلاینت)
├── components/
│   ├── planner/          # بخش‌های اصلی اپ (تقویم، کارها، عادت‌ها، ...)
│   └── ui/               # کامپوننت‌های shadcn/ui
├── hooks/                # هوک‌های React
└── lib/                  # تقویم جلالی، تعطیلات، تم‌ها، ذخیره‌سازی محلی
public/config.json        # تنظیمات عمومی (تبلیغ/ارتباط/خوشامد) — با گیت‌هاب ویرایش می‌شود
public/ads/               # عکس بنر تبلیغات
android/                  # پروژه اندروید Capacitor (بیلد APK)
.github/workflows/        # ساخت خودکار APK + کلید امضا در گیت‌هاب
```
